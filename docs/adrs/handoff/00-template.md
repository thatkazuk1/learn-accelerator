# Handoff NN: Short Task Name

> **Executor:** Provider or person responsible for the next step
> **Read first:** AGENTS.md, `docs/adrs/decisions/0001-architecture.md`, this handoff, and relevant reports
> **Language:** ASD-STE100 for all text
> **Scope:** Files and behavior in scope
> **Do not:** Read secrets, commit, push, deploy, run unapproved tests, or edit unrelated files

## 0. Why

State the goal and user-visible reason for the task.

## 1. Current State

Summarize what is already done and what remains.

## 2. Files Changed

List changed files and the reason for each change.

## 3. Next Step

State the exact next action for the next agent.

## 4. Acceptance Criteria

List the conditions that must be true before the task is complete.

## 5. Validation

List commands already run and their result.
List commands not run and why.

## 6. Risks

List known risks, missing inputs, and decisions that need the operator.

## 7. Handoff Notes

Give the next agent short operating notes. Include the preferred provider if
the task must switch providers.
When commits or branches are authorized, use Conventional Commits and
`<type>/<short-description>` branch names. Keep commit messages concise.
